# Edge Module

CDN/WAF/DDoS controls, managed load balancing, NGINX ingress and public API-gateway policies. Define TLS ownership, re-encryption/mTLS, route-specific body/header/time limits, coarse IP/device/facility throttles, WebSocket upgrade behavior and private/no-store clinical responses. Large documents use authorized direct-to-quarantine object-storage uploads rather than traversing API pods.
