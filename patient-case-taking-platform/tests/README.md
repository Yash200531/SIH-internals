# Test Strategy

- `contract`: APIs, events and FHIR profiles.
- `end-to-end`: patient-to-clinician workflows.
- `clinical-safety`: hazards, urgent symptoms, omissions and unsupported assertions.
- `model-evaluations`: language/accent/noise and model change gates.
- `security`: authorization, isolation, upload and prompt-injection tests.
- `accessibility`: keyboard, screen reader, comprehension and low-literacy testing.
- `performance`: interactive latency, queue throughput and recovery under load.

Clinical-safety and privacy tests are release blockers.
